# PBZCraft 预览验收

本机验证日期：2026-10-30。测试目标是确认 Minecraft 可以接入 PBZ 并产出独立启动预览，不是完整战斗适配。全部操作通过后台进程、Mod API、共享内存和本次进程窗口捕获完成，没有操作系统鼠标键盘输入。

## 0.0.2：当前完整一键包

用户实机反馈旧版不能输入、移动后卡死、F5 人物顿挫，并要求移除透明测试边界和原世界暂停。完成以下修复后，用户确认“没问题了现在打包”：

- 输入改为仅在本次 PBZ 进程处于前台时读取 Win32 键盘状态，原始鼠标消息由独立线程接收。MC 输入消息增加时间戳诊断，Host 记录输入队列、循环停顿和 MC 帧龄。测试代码没有注入操作系统输入；实际游玩由用户操作。
- 实际读取到卡死时原生碰撞返回 status 3，持续拒绝查询。原因是 MC 可以舍弃试探性台阶查询，而旧查询体回到起点时再次扫掠，被障碍物阻挡。现在直接重置查询体，再对请求的实际位移扫掠。Lua 回归检查覆盖试探查询后的回退、三米外继续移动、原生移动模式的交接与恢复。
- 删除三米/上下两米的活动范围保护；原生地形碰撞保留。单次请求仍有八米异常数据保护。原世界正常运行，只临时禁用本玩家的原生移动组件，避免与 MC 移动相互拉扯。
- 人物交换最短间隔改为 16ms，原生读取不再等待 100ms 世界列表轮询；顶点数不变时更新现有网格，人物平移单独跟随相机状态。实机 Host 观察到约 26 次人物写入/秒，不能据此声称保证 60fps。

`20261030-114325` 用户实机运行 137.6 秒，最大水平距离 225.4m，MC 最大 Y=274.793，F5 人物实际导入 5 个批次、1452 顶点，原生暂停状态读到 0。MC 记录的已完成碰撞查询拒绝数为 0，但存在 250ms 有界超时；输入事件到达 MC 的统计不包含全部原生渲染延迟。用户确认可用，不代表全图碰撞、战斗和跨场景验收。

完整包使用 `MinecraftBundle="."`，包含 Minecraft、Java 25、自包含的 .NET 8 Windows x64 Host，以及可移植 PowerShell。仅一个根目录入口 `一键启动PBZCraft.cmd`，不需要对方另装 .NET、PowerShell 或 Java，也不引用原来的 Duckov 安装路径。教程要求先在 Steam 正常建立原游戏存档，再将全部文件解压到同时有 `ProjectPBZ` 和 `platform` 的游戏根目录。

以全新 MC 目录测试实际根目录入口：将子进程 PATH 限制到 Windows 系统目录、DOTNET_ROOT 指向不存在的位置、清空 PSModulePath，不传限时参数。成功创建 MC 世界并进入原生场景；运行 171.0 秒取得 4229 个 MC 帧、3544 次透明窗口提交，最大水平距离 10.74m，原生暂停状态为 0。运行模块路径确认 Host 的 hostfxr/coreclr/WinForms 和 PowerShell 的 coreclr 均来自安装包目录。三端退出码 0，无强制清理，PBZ 存档及加载入口恢复校验通过。

中文和空格路径测试发现绝对路径写入 Java 参数文件会被本机启动器错误解码，导致 KnotClient 找不到。改用相对类路径、资源目录和工作目录后，同一中文/空格路径实际运行 118.6 秒，取得 2336 个 MC 帧、1751 次透明窗口提交，三端退出码为 0，存档与加载入口恢复通过。补充参数检查覆盖全 ASCII 参数文件、相对类路径和每个依赖文件存在。启动器发现 MC 异常退出会立即清理并报错；退出恢复时过滤仍被进程枚举暂时保留的已退出进程，避免误跳过恢复。

最终完整 ZIP 共 6797 个文件、792048289 字节，ZIP CRC 及排除项检查通过；6796 个已安装负载文件的 SHA256 与包清单完全一致。包不含个人存档、账户、日志、PDB 或生成 SDK。包内保留 Java、PowerShell、.NET、Fabric API 与桥接代码的相关许可。ZIP SHA256：`5d0d259803e26cffdc8dfc026b81e027427d1561ddacf373c21f5e6808b55edd`。测试结束恢复了本次打包前的 19 个 PBZ 存档文件并校验哈希，恢复原 MC 测试目录，停用本次代理加载入口。

尚未接入原作伤害、原生交互、跨场景；完整地形、防掉落、半透明、动态图集和原生光照仍未完成全范围验收。只适配固定 Steam build 26266538。以下 0.0.1 数据为历史验证，旧版暂停、三米边界、约 10Hz 人物和 mods-only 包描述均不代表当前完整包。

## 0.0.1 历史验证

## 根目录入口与恢复

真实调用根目录 `启动PBZCraft预览.cmd`，使用新的独立 MC 目录运行 150 秒（Host 140.6 秒）：三端退出码均为 0，`ForcedCleanup=false`、`ProxyRestored=true`、`SaveRestored=true`。MC 与 PBZ 持续连接，取得 4562 个 MC 帧、3930 次透明窗口提交。它是手动入口的启动/退出测试，没有实际按键输入，不能当作手感验收。

这次手动入口在场景首次接通时出现两次 250ms 碰撞查询超时，均返回零位移；从首次接通后的后续诊断到退出未再新增。已完成查询平均约 12.3ms。启动阶段短暂停顿和实际游玩手感仍需人工验收，不能据此声称输入零延迟。后台 `PrintWindow` 诊断捕获也会造成额外线程停顿。

根目录 `PBZCraft自动演示.cmd` 再运行 240 秒（Host 230.6 秒）：三端退出码均为 0，未强制清理，代理加载入口与存档均恢复并通过校验。取得 7468 个 MC 帧、6820 次透明窗口提交，传送确认 1、8235 个原生状态样本，背包与三种视角切换完成；短距离移动最大 0.741m、最大 MC Y=129.148，5 次区块更新，裂纹/掉落数据峰值 1/1。该运行禁用原生截图，结果中的 `firstSaved/thirdSaved/crackSaved` 只表示 MC 缓冲捕获，原生视觉证明来自上面的独立图形后端运行。

自动演示记录三次有界查询超时：两次在初次接通，一次在移动测试阶段；此后约三分钟未新增。不能把所有超时都归因于截图或首次纹理创建。已完成查询平均约 11.9ms，拒绝数为 0。

交付 ZIP 为 38 个文件、10,870,883 字节，CRC 与排除项检查通过；37 个已安装负载文件 SHA256 与包清单一致。ZIP SHA256：`ccf75d6bcb80834043b1f000d30cfec55a731de6c64706bbb9ba6907fa97a89a`。不含游戏本体、Java、测试世界、个人配置、日志、PDB 或游戏生成 SDK。

任务结束时另行恢复了首次测试前的 18 个 PBZ 存档文件，相对路径与 SHA256 全部一致。原 EXE 与原 MC 桥接 JAR 哈希均未改变，实际游戏加载目录中的代理 DLL 已停用，本任务进程数为 0。测试 MC 目录移入预览的备份目录，下一次启动会创建新的独立 MC 目录；日志与测试存档快照保留在本机，不进入分发包。

## 未通过或未覆盖

- 原世界持续暂停，水平范围三米、垂直范围两米；没有完整地图、跨场景、原生敌人战斗、伤害和交互验收。
- 附近未找到适合的独立竖直墙面，因此没有墙角/台阶/全地图防掉落验收。不能把局部地面成功推广到所有原生碰撞。
- 物理键鼠、长时间游玩、背包拖动、半透明方块、动态图集、投射物和完整光照未验收。人物文件交换约 10Hz。
- F9 结束两端；不支持恢复原版后留在本次进程继续游玩。
- 本包只含 Mod/桥接程序/加载器，复用本机自有 MC 和 Java；不是自带游戏本体的通用发行包。

所有 `-composite.png` 验证图均由本次原生窗口捕获与真实 MC HUD 缓冲离线合成。原生窗口截图本身不含独立透明窗口，合成图不应被描述为单张原始游戏截图。
